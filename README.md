# CampusHub Frontend

A lightweight frontend prototype for a **multi-tenant campus communication hub** that unifies announcements and channels across campuses while keeping each tenant's data separated.

## What is implemented

- Tenant picker (North, South, West campus examples)
- Shared communication channels rendered per selected tenant
- Central announcements feed scoped to the selected tenant
- Simple, framework-free frontend for easy extension
